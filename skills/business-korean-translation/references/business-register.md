# 비즈니스 한국어 표현

문체 선택 또는 해당 번역투가 실제로 문제일 때 필요한 부분만 읽는다. 표현을 일괄 금지하거나 문장 길이·어휘 다양성을 점수로 통제하지 않는다.

## 문서의 용도와 말투

| 용도 | 적용 |
|---|---|
| 내부 검토 보고 | 사실·해석·권고를 구분. 선택한 회사 양식에 맞춰 “검토한다/검토함” 또는 합니다체 |
| 거래처용 기획안 | 정중하면서 제안 내용·이점·조건·판단 요청이 보이게. 과장된 성과를 추가하지 않음 |
| 실행 계획 | 담당·행동·기한·선행 조건을 구체적으로. 표의 명사형과 본문의 연결된 문장 구분 |
| 읽기용 보고서 | 근거와 필요한 설명을 유지. 모든 문장을 불릿/짧은 명사형으로 바꾸지 않음 |
| 실시간 발표 | 근거 있는 핵심과 짧은 라벨. 조건을 삭제해 의미가 달라지지 않게 |

“더 자연스럽게”는 반말/구어체를 뜻하지 않는다. 사용자 문장 예시와 선택한 종결을 우선하고, 주어가 달라지거나 책임이 불명확할 때만 조직명을 다시 쓴다.

## 직역 대신 실제 행동

| 원문 표현 | 문맥에 따라 선택 | 보존할 구별 |
|---|---|---|
| 検討・確認 | 검토·확인 | 검토가 승인/결정으로 바뀌지 않음 |
| 調整 | 일정/조건 조율, 수치/배치 조정 | 상대와 협의하는지, 값을 바꾸는지 |
| 対応 | 문의 답변, 문제 조치, 상황 대응 | 접수/조치/완료를 구별 |
| 共有 | 자료 공유, 결과 전달, 의견 교환 | 실제로 어떤 내용을 누구에게 주는지 |
| 実施・開催・推進 | 시행/실시, 행사 개최, 추진 | 실행인지 예정인지 유지 |
| 見込み・目安 | 전망/예상, 참고 기준/대략 | 보장·확정 금액/기한으로 바꾸지 않음 |
| 実績・計画 | 실적·계획 | 과거 측정과 미래 계획을 구별 |

“본사/당사/지사”는 어느 조직인지 확인된 범위에서 쓴다. 법인과 지점을 혼동하거나 독자의 국적만으로 “국내/해외/현지”를 바꾸지 않는다. 공식 이름이 있으면 보존하고, 한국어 공식명이 없는 명칭을 임의로 만들어내지 않는다.

## 한국어 문장 흐름

- “~에 있어서의 ~에 대한” 같은 긴 조사 연결은 주체·행동이 읽히는 순서로 다시 쓴다. 필요한 “~에 대해/통해”까지 없애지 않는다.
- “실시의 추진을 행한다” 같은 명사열은 확인한 행동으로 풀어 쓴다. 조치 주체가 중요하면 이름을 남기고, 수동 표현이 사실에 맞으면 유지한다.
- 긴 수식어는 수식 대상 가까이 둔다. 여러 독립 행동은 문장을 나눌 수 있지만 승인 조건·예외를 그 행동과 떨어뜨리지 않는다.
- 반복 접속사와 소제목의 재진술을 줄인다. 문장 관계가 분명한 곳에는 불필요한 “또한/따라서/중요하게도”를 덧붙이지 않는다.
- 표와 제목의 명사형은 역할에 맞게 쓴다. 전문 용어를 다양한 동의어로 돌려 쓰지 않는다.
- 한글 띄어쓰기·주술 호응을 지킨다. 자연스러움을 이유로 맞춤법을 일부러 흐트러뜨리지 않는다.

숫자와 조건은 명확하게 유지한다. “전년 대비 12% 증가”와 “12%포인트 상승”, 부가세 포함/별도, 상한/예상/확정, 기간 한정/상시를 혼동하지 않는다. 본문의 자연스러운 호흡과 페이지의 줄바꿈은 각각 검토한다.
