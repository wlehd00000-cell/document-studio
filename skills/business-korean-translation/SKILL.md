# 자연스러운 비즈니스 한국어 번역·윤문

보고서·기획안·계획서·발표자료의 문장을 한국어 독자가 쉽게 이해하고 판단하도록 다듬는다. 대화 언어와 완성 문장의 언어를 구분하고, 상위 작업의 독자·목적·사용 상황·사용자 문체·용어·위임을 이어받는다.

## 공통 품질을 적용하기

[공통 번역 품질](../report-html-pptx/system/translation-quality.md)이 사실·수치·조건·확정도 보존, 원문 대조, 한 원고에 반영하는 절차를 관리한다. 신규 문서도 제공 자료를 먼저 비변형 확인할 수 있다. 짧은 문구나 범위가 정해진 수정에는 전체 질문을 반복하지 않는다. 책임·조건·판단을 바꾸는 모호함만 확인하며, 원문이 없으면 번역을 만들어내지 않는다.

문서 전체는 [문서 라이팅](../document-writing/SKILL.md)이 조정한다. 같은 원고에서 맡은 범위를 수정하고, 한국어 작업을 위해 일본어 전문까지 기본으로 읽지 않는다. 회사 양식과 사용자 문체 예시를 우선한다.

## 한국어 어순과 업무 문체

문장의 기능과 관계를 이해한 뒤 한국어 어순으로 옮긴다. 긴 조사 연결·명사열·불필요한 피동을 풀고, 확인한 행동을 구체적으로 쓴다. 주체가 달라지거나 책임이 불명확할 때는 조직명을 남기고, 문맥이 명확하면 자연스럽게 생략한다. 좋은 원문은 그대로 둘 수 있다.

“더 자연스럽게”를 반말·블로그체로 해석하지 않는다. 선택한 “검토한다/검토함” 또는 합니다체와 문장 호흡을 유지한다. 감정·성과·사견을 덧붙이거나, 자연스럽게 보이도록 맞춤법을 흐트러뜨리지 않는다. 제목·표의 명사형과 본문의 연결된 설명을 구분한다. 발표용은 핵심을 줄여도 조건을 보존한다.

“본사/당사/지사/현지법인”과 “국내/해외”는 원문의 실제 조직·국가를 따른다. 독자의 국적만으로 시점을 바꾸거나 한국어 공식명이 없는 이름을 만들어내지 않는다. 전문 용어를 다양한 동의어로 돌려 쓰지 않는다.

## DEMO 보고서의 장문과 줄 흐름

상세 한국어 본문은 [DEMO ESG 문체](../document-writing/references/demo-esg-writing.md)와 [자연스러운 장문 전개](../document-writing/references/demo-esg-korean-longform.md)의 배경·목적 → 구체적 실행 → 결과·한계·후속 방향 관계를 활용한다. 원문에 근거가 있는 설명을 보존하고, 인과나 성과를 추가하지 않는다. 긴 원고를 짧은 문장 나열로 바꾸지 않는다.

[한국어 줄바꿈](../document-writing/references/demo-esg-korean-lineflow.md)은 실제 출력에서 별도로 검토한다. 일본어판의 글자 수만 기준으로 내용을 생략하지 않는다. 어순과 문장 호흡을 정리하되 의미·조건을 유지한다. 본문·표·차트·사진 설명·도식의 용어를 맞춘다. 서체와 밀도는 상위 문서의 목적별profile에 따르며, 표지·발표자료에 상세 본문 활자를 기계적으로 적용하지 않는다.

## 필요한 참조와 전달

- 문체·일본어 직역이 문제일 때: [비즈니스 표현](references/business-register.md)의 해당 항목.
- 실제 오류에 예시가 필요할 때: [원문과 번역 예시](references/translation-examples.md)의 관련 사례.

직원에게 도구·사전·내부 스킬·변환 기술을 고르게 하지 않는다. 공통 품질 대조와 필요한 한국어 검토를 끝낸 뒤 요청한 형식으로 완성 원고를 준다. 글 넘침이 없다는 사실만으로 번역 정확성·자연스러움·사용자 수락을 확정하지 않는다.
