# Synthetic visual styles

- **Quiet editorial:** generous margins, one dominant message, muted accent.
- **Explanatory process:** editable connectors, consistent icon weight, explicit input/output labels.
- **Evidence-led:** a quantified chart adjacent to its method and source.
- **Expressive concept:** visually rich cover illustration labeled as a concept, not a photograph.

Reference galleries in this repository are independently authored fictional studies. Real documents should follow the user's brief and rights-cleared assets.
