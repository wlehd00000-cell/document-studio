# Public visual reference index

The included Lucide and Phosphor icons retain their upstream licenses. The 72 schematic SVGs are independent chart/diagram examples with invented values. The synthetic casebook at [`demo-esg-casebook.json`](../../report-html-pptx/references/demo-esg-casebook.json) uses fictional companies A/B/C; its case IDs are **not** measured pages of real reports. No external corporate PDF, logo, screenshot, source excerpt or historic production acceptance is distributed.

## Choosing a visual

- For an exact quantity: chart with unit, denominator and source.
- For a workflow: editable flow with named inputs and outputs.
- For alternatives: comparison grid with common criteria.
- For an imaginative opener: synthetic illustration with explicit concept label.

Before production, verify the actual project's source and asset rights. Do not interpret the illustrative graphics as current business data.
