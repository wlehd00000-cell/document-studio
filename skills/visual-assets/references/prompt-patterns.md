# Compact production prompt patterns

Use a pattern only when it clarifies the current asset. These are examples of prompt structure, not default compositions or literal tool arguments. Substitute the real brief and reference roles; omit irrelevant lines.

## Shared set specification

```text
Use: [document's visual job and final placement].
References: [Image/File A = style anchor; B = subject original, if actually available].
Shared style: [chosen family, color roles, projection/geometry, material/light, proportions].
Preserve: [official source identity and confirmed relationships].
Text: [no embedded text; or exact explicitly required markings].
```

Record the shared block once. Each asset adds its own subject, relation, composition/crop and constraints. A generation call still receives the relevant complete prompt and available references; a file containing the common block is not a magical style-lock API.

## Integrated main scene

```text
Create [concrete subjects] in one continuous [space/view] explaining [relationship].
Show [confirmed actions/arrangement], retaining [direction/order when relevant].
Primary focus: [what must be read first]. Supporting areas: [what supports that focus].
Extend [appropriate contextual ground/background] naturally to the canvas edges.
Keep [designer-specified region] quiet enough for editable document overlays.
Apply the shared style. Use [requested ratio/framing]; preserve [crop invariants].
Do not depict proposed links as established infrastructure or actual DEMO facilities.
```

Do not invent a literal supply route or use arrows just to fill the image. Use flow, grouping or spatial proximity only where its meaning is supported. The scene can be flat, panoramic or isometric according to the designer's brief.

## Supporting illustration

```text
Depict [concrete subject/action] so the reader understands [one visual job].
Use [composition appropriate to placement], consistent with the shared anchor.
Keep [necessary identifying elements] visible at [actual use size].
Background: [transparent / document-compatible / contextual, as needed].
```

An abstract concept can use a restrained metaphor when it improves understanding; it must not imply unconfirmed performance, scale or evidence. Avoid automatically filling every illustration with floating blobs, sparkles, glossy spheres or tiny unrelated figures.

## Related series

```text
Keep [stable geometric/style traits] from [fixed anchor].
Change the theme to [new subject] with [intentional emphasis/shape] while preserving
[palette roles, detail/weight and projection]. Adapt the crop to [new placement].
```

For small pictograms, use geometric vector family rules rather than a rich-scene prompt. For requested bitmap pictograms, keep the representation simple and inspect all members at the intended small size.

## Targeted revision

```text
Edit [actual target]. Change only [specific requested feature/region].
Keep [subject identity, relationships, geometry, palette roles and other invariants].
Match [fixed reference]. Preserve [background/alpha and crop] unless asked otherwise.
```

A main scene revision may affect its spot details or crops; recheck those consumers without rewriting every asset. Text/number corrections in editable document layers go back to writing/design.

## Full-image cover / editorial background

```text
Page role: [cover/chapter/editorial] for [reading/approval/proposal/live purpose].
Create [actual authorized subject or explicitly fictional conceptual subject].
Let the scene continue naturally to the canvas edges.
Dominant subject and focal point: [where/what]. Camera/view: [purposeful view].
Quiet text zone: [specific requested local area and contrast character].
Protect [identity/detail] within the permitted [crop/frame].
No business title, labels, numbers, metadata or meaningful arrows in the image.
Those are editable document overlays. Source status: [actual/concept/proposal].
```

Planned region coordinates do not prove the result has those regions. Inspect the actual image and return usable measured/approximate focal/crop/text zones with coordinate units. Do not add a global border or white margin to a full-image brief.
