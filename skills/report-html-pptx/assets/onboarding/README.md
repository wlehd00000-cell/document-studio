# Legacy onboarding assets

These files are retained for compatibility with existing HTML, imports and tests. They are not the current first-use flow. Do not open, render or troubleshoot them for ordinary startup.

Use [chat quick start](../../references/staff-onboarding.md). The plugin's onboarding MCP connection is disabled. Staff answer directly in chat without a separate screen, summary confirmation or JSON transfer.

Existing files may still be inspected when a user explicitly asks to maintain a legacy file. Draft widget state does not establish submission or authorization.
