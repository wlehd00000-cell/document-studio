# Independent demo brand

`demo-mark.svg` and `demo-mark-white.svg` are original abstract text-only marks created for this fictional Document Studio example. They do not represent any employer or registered brand. Replace them with your own licensed client logo before producing a real document.

System font fallback is used in this source-only public package. Optional locally installed Pretendard font files are not bundled; see `references/font-setup.md`.
