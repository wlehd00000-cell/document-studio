# 목적과 주제에서 출발하는 디자인

[Canonical design system](../system/design-system.md)의 purpose profile과 page family를 선택한다. [DEMO actual cases](demo-esg-design.md)의 읽기 순서·이미지 힘·공간 관계는 강한 기준이며, 모든 문서를 동일 ESG 본문형으로 만드는 규칙은 아니다. 현재 real final-language text/actual assets/evidence로 첫 composition을 만든다.

## Art direction과 body composition

Cover는 별도 문제다. 문서의 주제/목적을 한 번에 이해할 dominant image/object/type를 고르고 제목과 image의 관계, negative space, crop, quiet zone, metadata의 크기를 먼저 설계한다. Full-image photo/concept, product hero, location image, strong crop, typography-led, institutional cover를 자연스럽게 선택한다. 장식 white-title-logo cover를 자동 반복하지 않는다. 별도 cover가 짧은 승인자료에 불필요하면 추가하지 않는다.

Chapter opener는 주제 전환을 돕는 큰 장면/type와 필요한 탐색만 둔다. Editorial page는 큰 subject와 읽기 rail을 결합한다. Body는 충분한 근거·조건·표·문단·사진을 읽게 한다. Cover/opener에 body 최소밀도·3단·7px band를 강제하지 않는다. Live deck에는 먼 거리 hierarchy와 발표 sequence를 설계하며 detailed reading deck을 단순 확대하지 않는다.

각 주요 page map에 한 문장의 design intent를 남긴다. 독자가 먼저 볼 대상, 설명 관계와 다음 읽을 지점을 실제로 명시한다. 같은 추상 문장을 모든 page에 복사하거나 디자인을 설명하는 별도 장문 보고서를 요구하지 않는다. One-shot/delegation은 합리적인 한 방향으로 완성하고 사용자 비교 요청 때만 2–3 actual equivalent alternatives를 보여준다.

## 읽기를 만드는 craft

위계는 크기/굵기/간격/위치가 맡는다. 제목은 본문을 읽어야 할 공간을 과하게 밀지 않는다. 같은 주제의 간격보다 주제 사이를 넓히고 실제 label/caption을 가까이 둔다. 중요한 사진은 충분히 크게, 비교사진은 optical scale와 실제 대상을 맞춘다. Mixed-ratio group은 [image composition](demo-esg-image-layout.md)의 공통 height/edge/caption 기준을 선택한다.

DEMO palette는 범주/강조 역할로 사용하며 status는 text도 함께 표시한다. 조건/출처/가는 선은 실제 크기에서 대비를 확인한다. Official logo/product/character를 재생성하거나 identity를 없애지 않는다. Native labels/charts/table copy는 편집 가능하게 보존한다.

여백은 역할로 판단한다. Cover의 quiet area와 opener의 의도한 여백을 채우기 위해 slogan/stock photo를 추가하지 않는다. Detailed body의 불필요한 underfill은 관련 설명·근거를 연결하거나 통합하되 자료가 없으면 허구로 채우지 않는다. 긴 본문을 카드 3개나 icon 3개로 요약하지 않는다.

Rounded cards, pale block+narrow colored edge, 가상 progress, oversized number, 매쪽 동일 3-column, 무관한 stock, 과도한 glossy/gradient를 자동 기본값으로 삼지 않는다. 실제 동등 단위를 묶는 card, 공식 template/asset의 effects는 목적에 맞게 유지한다. 다양성은 레이아웃 quota가 아니라 reader question에 답하는 결과다.

## 검토

핵심 관계/배치 → 위계/밀도 → 문자/crop/caption → 세부 정렬 순으로 묶어 수정한다. 전체 sequence와 변경/밀집/긴 한일/신규 image page를 실제 크기로 본다. 합의한 방향을 근거 없이 계속 바꾸지 않는다. [DEMO review](demo-esg-review.md)와 [project state](../system/project-state.md)의 release 판단을 따른다. Structural pass는 editorial/visual/export/user acceptance의 대체가 아니다.

## 본문 전개와 소제목

[표 의존·설명 방식·반복 검수](visual-expression-and-rhythm.md)를 실제 본문 순서에 적용한다. 이미지와 여러 시각화 방법을 의미에 맞게 구현하고 반복 유지의 이유 또는 바꾼 구도를 QA에 남긴다. [보고서 소제목](report-heading-style.md)은 명사형으로 작성하며 예상/제안/완료 상태를 보존한다. 발표자료의 문장형 메시지 제목을 보고서에 자동 적용하지 않는다.
