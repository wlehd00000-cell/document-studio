# Document-family editorial logic and source review

Use this reference only for substantive argument design: lectures, strategic proposals, persuasive presentations, research-led reports or a user-requested editorial overhaul. Routine formatting, translation, single-line fixes and accepted-layout revisions skip it.

## 1. Start with the actual reading or presentation job

Use the existing brief/map/copy as one working record. Record the intended reader, purpose, decision or use, evidence gaps, constraints and required document family. Choose a thesis and explanation order for persuasion/education, a decision frame for approvals, task flow for instructions, and scope/method/results for analytical documents. A provisional thesis is a hypothesis, not a fact. Do not turn an ordinary report into a talk.

## Document-type page contracts

Choose the row that matches use and preserve accepted templates. These are composition checks, not mandatory identical page layouts:

| Document form | Page/section design checks |
| --- | --- |
| Live lecture or persuasive presentation | Audience question, one main takeaway, evidence/example, prerequisite, transition, on-screen text, speaker/visual time — **only for live explanatory narratives** |
| Reading report | Section purpose, relevant findings, explanation, source/evidence location, qualifications, figure-caption relationship, reading hierarchy and navigation |
| Approval/decision brief | Decision requested, recommendation or options, approval criteria, risks/costs/conditions, accountable follow-up; put the decision where a reviewer can find it |
| Proposal or execution plan | Context/objective, alternatives, proposed solution, feasibility, sequence, owners, timeline, budget, risk, measures of success; organize to the reader's decision |
| Operations/SOP/staff guide | Trigger, required inputs, steps, examples, responsible owner, exceptions, quality check and handoff; enable scanning and repeatable use |
| Research/analytical brief | Definitions, methodology, scope, comparison basis, findings, limits and implications, with faithful units/denominators |
| Existing template or form | Preserve **field order and required labels**, fixed sections, permitted page geometry and exact values; improve text within constraints |

For any family ask: is the necessary content present, accurate, findable, comprehensible, nonredundant and placed near the evidence it explains? For multi-page work, give each unit a justified contribution and keep references consistent. **Do not invent a slide-like transition** at the end of a report page, table, checklist or form. Only use `audience_question`, `previous_link`, `takeaway`, `next_bridge`, `visual_motion_job` and `estimated_time` as narrative fields when that presentation job truly needs them.

For live presentations, apply necessity, prerequisite order, distinct cognitive job, nearby support, earned transition and final payoff. A recurring scenario helps continuity when it is genuinely clarifying; label any hypothetical output or conceptual system. Motion should reveal transformation, responsibility, comparison or time, not substitute for evidence.

## 3. Let evidence reframe the story when needed

Research starts with answer-changing questions, not a source-count target. Primary material and original empirical methods outrank summaries for consequential claims. For novel technology, verify names and distinguish base model, specialized model, search capability, orchestration layer and application; do not compare cross-level products as if they are the same type.

A new source returns one of:
- **confirm**: supports the current claim; preserve the map;
- **qualify**: limits a claim, page caption, example or date/region;
- **contradict**: remove or correct the unsupported statement;
- **reframe**: changes the thesis, explanation order or downstream implication.

For `contradict` or `reframe`, name affected page IDs, replacement takeaway and required transition changes; update the one canonical copy. A material source conflict triggers focused verification. Stop once the reader decision is adequately supported and further search is unlikely to change it.

## 4. Write for the actual medium

A reading report keeps the explanation, source and conditions together on the page; an approval brief highlights the requested decision; a staff guide prioritizes scannable action steps and exception handling. A live slide shows essentials and sends full explanatory language to speaker notes or a manuscript. A speaker manuscript should preserve the exact spoken text and separate source notes, on-screen labels, cue/motion notes and fallback demonstrations. Script length is only a timing estimate; include transitions and non-speaking moments and calibrate with a read-through when possible. Claims of a completed timed rehearsal require that it actually occurred.

The last editorial pass reviews the whole artifact for its selected use. For presentations check thesis continuity, transitions, terms and time. For reading reports check findings-to-evidence navigation and the integrity of sections. For approvals check decision sufficiency; for operating guides check steps, ownership and exceptions; for templates check required fields. In every form check redundant material, claim-to-source fidelity, hypothetical labels and honest temporal/causal claims. For source-backed numeric comparisons keep unit, period, scope, denominator and limits.

## 5. Lightweight and testable

Use the existing brief, page map, canonical copy and source ledger. An ordinary task needs no new QA application, database, second draft or mandated fixed number of alternatives. Verify changed sections and adjacent transitions; reuse accepted unaffected parts. For full formatted production keep the separate layout/export gates.

Three regression examples for reviewers:
1. A new specialist concept discovered midway through a 15–20 page lecture should revise its taxonomy pages and downstream implications, with citations and transitions; not append a random slide.
2. A formal two-page Japanese approval report with sufficient supplied facts should finish in the existing report voice and production path, with no forced dramaturgy or deep research.
3. A bounded wording change on one approved page should preserve other page choices, evidence and layout reviews unless its meaning changes a dependency.
