# Document Studio クイックスタート（公開デモ）

目的、対象読者、判断事項、言語、形式と資料を伝えてください。確定事項を繰り返し質問せず、未確定事項は明示します。

- **ワンショット:** 根拠確認、構成、執筆、設計、変換、検査。
- **共同作業:** 重要な決定を段階ごとに確認。
- **深掘り企画（明示的な依頼のみ）:** 主張の検証、独立調査、構成案と初期デザインの比較。

練習例：「架空の物流会社の業務引き継ぎ改善案を、日本語のA4・4ページ資料として作成してください。数値はすべて仮定と明記してください。」

実在企業の資料、商標、非公開データは権限を確認してから扱ってください。
