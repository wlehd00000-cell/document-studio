# Portable document examples

The staff distribution uses synthetic examples in examples/document-sample-a4.html and examples/document-sample-slides.html. Their sample values and organizations are fictional and explicitly labelled. They are layout references, not evidence or company targets.

Use only a matching fragment:
- A4 reading pages: a finding with comparable bars; an execution timeline and responsibilities.
- Japanese presentation pages: a proposal structure; an option comparison and requested decision.

Inspect the corresponding example at actual size when borrowing it. Keep the actual project's sources, language, page count and template authoritative. These examples are not mandatory designs or a fixed number of pages. The package does not require the author's past project files or personal paths.
