# 표 의존을 줄이고 설명 방식과 페이지 전개를 고른다

새 전체 문서는 사용자가 채택한 [가이드 구성 기본값](accepted-composition-default.md)과 [실제 HTML](../assets/accepted-staff-guide/index.html)의 관련 본문을 현재 내용으로 적용한다. 일상 제작에서 이 수준의 설명 관계와 전개를 구현하며, 기존 채택 양식과 현행 필수 선택은 보존한다.

독자 질문과 실제 근거를 먼저 보고 표현을 고른다. 표는 정밀한 값 조회, 여러 항목의 같은 기준 비교, 필수 양식에 유용하다. **내용을 정리하기 편하다는 이유로 모든 설명을 표에 넣지 않는다.** 논리적 연결·브랜드·용어의 일관성과 설명 방식의 획일성을 구분한다. 모든 페이지에서 배경→요약 표→기대 효과를 반복하면 다른 제목이어도 지루해진다.

## 이해할 관계에 맞는 표현

- 대상의 모습·현장·사용 맥락: 확인된 사진, 제품 이미지, 핵심 장면, 주·보조 사진과 가까운 설명. 물성·경험·제안 장면은 개념 이미지/일러스트로 구체화할 수 있다.
- 전체와 중요한 세부: 전체 이미지+같은 원본 확대, native 번호·국소 라벨·주석. 무엇을 살펴봐야 하는지 실제 대상과 연결한다.
- 변화와 개선: 같은 기준의 전후 이미지, before/after 도식, slope/dumbbell 차트와 변화 이유. 비교 조건과 예상/실측 상태를 보존한다.
- 순서·절차·사용 경험: 과정도, 타임라인, storyboard, 사진 시퀀스, journey. 단계별 입력·산출물·책임·조건을 표시한다.
- 연결·의존·구조: 관계도, 계층도, 연결 장면, exploded view, 지도·동선·system diagram. 실제 관계를 공간으로 설명하며 미확인 인과는 가설로 표시한다.
- 규모·추세·차이: 막대, 선, dot, 분포, small multiples 등 실제 데이터 질문에 맞는 차트. 수치가 없으면 수치 차트를 만들지 않는다.
- 판단·선택·실행: 옵션 비교, 결정 트리, 조건 분기, 로드맵·간트·담당 흐름. 표가 정밀한 비교에 가장 유용하면 표를 유지한다.
- 해석·맥락·조건: 충분한 연결 문단, 핵심 문장과 근거, 사례의 사진/도식. 모든 문단을 균등 카드나 항목표로 축약하지 않는다.

[visual reference library](visual-reference-library.md), [body composition](body-composition.md)과 실제 본문 예시는 현재 설명 관계에 맞는 것만 고른다. 위 목록의 순서나 일정 비율을 강제하지 않는다. 큰 숫자, 아이콘 장식, 색상 변경은 근거가 설명되는 시각화의 대체가 아니다.

## 계획에서 실제 자산까지

기존 page map에 독자 질문, supported message, explanation_form, narrative_move, dominant element, 읽는 순서와 선택 이유를 짧게 남긴다. explanation_form은 photo / annotated_image / illustration / process / relationship / chart / timeline / prose / table / mixed 등 실제 지배적 설명 방식이다. narrative_move는 문제 제기, 근거 해석, 작동 원리, 사례 확대, 선택 판단, 실행 조건 등 이번 페이지가 앞쪽에서 무엇을 진전시키는지다. 페이지마다 모든 항목을 장문으로 다시 쓰지 않는다.

이미지가 이해를 돕는 본문에서는 적절한 사실 원본을 찾거나 [visual assets](../../visual-assets/SKILL.md)에 개념 자산 제작을 연결해 **실제 파일을 배치**한다. ‘이미지 권장’ 메모·빈 자리로 끝내지 않는다. 생성 이미지에는 무엇을 설명하는 장면인지, 대상·시점·crop·native 설명 공간을 전달하고 결과를 확인한다. 사실 사진과 개념 장면을 구분하며 중요한 한일 텍스트·수치·조건·설명선은 편집 가능한 요소로 유지한다. 자산 접근이 실제로 제한되면 도식/원고로 가능한 관계를 구현하고 미확인 범위를 알린다.

## 반복을 구체적으로 검토한다

3쪽 이상 본문에서 같은 지배적 형식 또는 같은 서술 움직임이 연속 3쪽 이어지거나, 표가 본문 절반 이상을 지배하면 다시 고를 신호다. 표·본문 부록, 정밀 규격 비교, 공통 의무 양식, 비교 가능한 시리즈에는 반복이 합리적일 수 있다. 이는 상한·표 금지·강제 이미지 할당량이 아니며 페이지별 설명 필요로 판단한다. 1–2쪽 문서를 다양성 때문에 늘리지 않는다.

표를 색 카드나 줄 목록으로 바꾸고 동일 항목·읽기 순서를 유지한 것은 표현의 변화로 세지 않는다. 사진만 바꾼 같은 좌우 분할도 동일한 전개다. 같은 배경→항목 나열→결론이 반복되면 논리의 진행 자체를 고친다: 필요한 근거를 묶고, 작동 원리/사례/전후/결정/실행으로 실제 질문에 답한다. 전역 흐름은 유지하고 근거 없는 놀라움이나 임의 순환을 만들지 않는다.

## 실제 순서 검수

표지를 제외한 본문을 연속해서 훑고 대표 상세 페이지를 실제 크기로 읽는다. 새로운 이해가 생기는지, 이미지/차트가 해당 원고를 설명하는지, 상세 조건이 살아 있는지 확인한다. 기존 QA 메모의 sequence_review에 문제 페이지, 대안과 적용 결과 또는 반복 유지의 구체적 이유를 남긴다. ‘다양함’ 한 줄이나 자동 검사 통과로 끝내지 않는다.

HTML 페이지에는 가능하면 data-dominant-form과 data-narrative-move를 실제 구도와 일치시킨다. data-page-role로 cover/chapter_opener/appendix를 구분한다. check_document.py는 반복 annotation과 표 존재 비중의 후보만 경고한다. CSS·면적·시각적 지배·위장 카드와 실제 논리의 반복은 자동 판정하지 못하므로 최종 순서 검토가 필수다. 의도한 반복의 주석도 실제 검토를 대체하지 않는다.
