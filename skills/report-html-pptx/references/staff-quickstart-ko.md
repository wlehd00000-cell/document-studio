# Document Studio 사용법 — 공개 데모

문서 목적, 독자, 판단할 항목, 언어, 형식과 자료를 알려 주세요. 사용자가 확정한 조건은 재질문하지 않으며, 미확정 항목은 명시적으로 표시합니다.

- **원샷:** 사실 확인 → 구조 → 집필 → 디자인 → 변환 → 결과 검수까지 가능한 범위에서 실행합니다.
- **협업:** 각 단계의 핵심 결정을 사용자와 검토합니다.
- **심층 기획(명시적으로 요청한 경우):** 주장 검증과 외부 리서치, 논리 대안과 초기 시안 비교를 먼저 수행합니다.

연습 예시: “가상의 소매 서비스 조직을 대상으로 고객 동선 개선안을 한국어 4페이지 A4 문서와 편집 가능한 슬라이드로 만들어줘. 숫자는 모두 합성임을 표시해 줘.”

실제 기업 정보·비공개 자료·상표는 권한을 확인한 다음 사용하세요. 공개 저장소의 모든 사례는 가상입니다.
