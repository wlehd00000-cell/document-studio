# Structure owner

Load [architecture](../../document-architecture/SKILL.md) for actual outline/argument work. It owns supported questions/messages/conditions and the existing map. Reuse accepted structure for local changes.

[Orchestrator](../SKILL.md) owns current intent/completion, [writing](../../document-writing/SKILL.md) owns copy and [design](../../document-design/SKILL.md) owns HTML. [Body relationships](body-composition.md) are choices, not a fixed page order. [Routes](../system/authoring-routes.md) fixes HTML and default conversion; source templates cannot select native authoring.
