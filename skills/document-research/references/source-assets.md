# Actual source-asset handoff

Only read when a document needs a photograph, source figure, map or capture. Start from the reader question: the actual object/place, time and fact to show. Architecture specifies meaning; design specifies final placement/crop/output. Acquire only the useful material.

| Needed record | Meaning |
|---|---|
| IDs | asset_id, source_id and affected section/claim IDs |
| Availability | acquired, pending, unavailable or restricted; mark what actually happened |
| Actual file | Existing project-relative path, format and useful intrinsic size/resolution; hash when needed to track revisions |
| Original location | Supplied file or origin URL, exact page/figure/table/region, publisher, publication/capture date |
| Support and limits | What it shows, period/population/units, concept/proposed/completed status and what it does not prove |
| Use/edit constraints | Known attribution and access/rights status; preserve protected logos, characters, products and geometry |
| Transformation | Separate original and crop/converted/captured derivative; state actual edits and relevant capture context |

Use the existing evidence record and, when needed, content/visual-assets.json. Files used by HTML belong in html/assets/ with relative references. Keep working originals where the project normally stores them; avoid duplicating large files without need.

PDF page captures retain the exact locator. Browser captures use an actually supported surface. An unreadable numerical chart is not enough to rebuild its data. A search thumbnail does not establish identity, rights or useful resolution. Do not download remote media merely to work around display restrictions.

If acquisition fails, leave a useful original locator, intended crop/subject, reason and alternative. Missing real evidence may use a text/table explanation or a clearly marked concept, but not fabricated event/product photography presented as fact. Do not install or connect tools without the relevant consent.

The asset producer returns fabrication-specific records separately. Writing finalizes captions/alt text; design checks final-size identity, crop and clarity. Source verification does not certify final composition or user acceptance.
