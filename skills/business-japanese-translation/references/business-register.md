# ビジネス日本語の文体と用語

文体の選択や、実際に直訳が問題になる箇所だけ参照する。表現の一律禁止、固定文字数、語尾のランダム化で自然さを作らない。

## 用途に合わせる

| 用途 | 文体・説明 |
|---|---|
| 社内報告 | 事実・解釈・提案を区別。会社の様式に沿った常体または敬体 |
| 取引先への企画提案 | 丁寧で明確に。提案内容、実行条件、依頼する判断が分かる文章 |
| 実行計画 | 担当・行為・期限・前提条件。見出し/表の名詞句と本文の文を区別 |
| 閲覧用の報告書 | 十分な根拠と説明。全体を体言止めや短い箇条書きに圧縮しない |
| 口頭説明用の資料 | 要点を絞った大きなラベル。省略で適用条件を変えない |

敬体/常体と句読点は、採用した見本にそろえる。丁寧さを上げても意思決定や行為の主体を隠さない。「させていただく」をすべて禁止せず、実際の関係と必要性を判断する。報告書に個人的な感情や口語の揺れを追加しない。

相手の会社は、書面では通常「貴社」、会話では「御社」を使う。自社の「当社」「弊社」は文書の関係と社内様式に合わせる。引用文や正式名称は、この慣習を理由に書き換えない。

## 韓国語からの直訳を解く

| 原文 | 文脈で選ぶ表現 | 区別 |
|---|---|---|
| 진행 | 進める、実施する、開催する、手続きを行う | 何を行うかと、予定/実施済み |
| 검토 | 検討する、確認する、審査する | 検討と承認/決定を区別 |
| 공유 | 資料を共有する、結果を伝える、意見を交換する | 対象・相手・行為を保つ |
| 대응 | 問い合わせに回答する、問題に対処する、対応する | 回答/処置/完了を区別 |
| 협의·조율 | 協議する、日程/条件を調整する | 合意済みとは限らない |
| 추진 | 計画を進める、施策を推進する | 計画と実行の確定度 |
| 전망·목표·실적 | 見込み・目標・実績 | 予測/意図/測定済みを区別 |

「본사・당사・지사・현지법인」は、それぞれの組織を確認してから本社・当社/弊社・支店/支社・現地法人などを選ぶ。会社名が曖昧なら主体を補わず確認する。支店と別法人を入れ替えない。韓国側の視点の「国内」を自動的に日本国内に変えない。

## 読みやすさと責任の明確さ

- 主語と述語を対応させ、長い修飾を対象の近くに置く。主体が変わる箇所では組織名を明示し、明らかなときは自然に省略する。
- 「〜における」「〜に関して」「〜ということ」「実施を行う」は文脈で整理する。必要な制度用語や引用には機械的な置換をしない。
- 二重否定、受身の連続、同じ接続詞の反復を解く。意味のある否定・対比・専門用語は残す。
- 推奨は推奨として、未定は未定として書く。遠回しな敬語や「と思われます」を増やして条件と責任をぼかさない。
- 同じ用語を本文・表・図でそろえる。固有名詞、識別子、公式名称を一括で全半角変換しない。
- 金額、通貨、税込/税抜、割合/ポイント、年月日、タイムゾーンは原文の意味を保つ。単位表記の変換と通貨換算を区別する。

文を整えた後は、実際のサイズで禁則と意味の切れ目を確認する。名前や重要な数値/単位のみ必要に応じて保護し、全語をnowrapにして文字を縮めない。韓日併記は別々の適切な言語タグ/改行規則を使う。
