현재 평가 대상: 가상 자료 또는 배포 허가를 확인한 공개 자료입니다. 비공개 사내 자료 기반의 내부 배포는 미지원입니다.

01 / OPERATING MODEL

관리자 준비와 직원의 문서 제작을 구분합니다.

회사 규칙을 정리하는 과정과 요청마다 자료를 만드는 과정은 별도입니다. Document Studio는 두 과정을 지원하는 스킬과 스크립트를 묶습니다.

A / 관리자가 준비할 것

  1. 01

    참고 자료 선택

    분석·배포 권한을 확인하고 PDF·PPTX 참고 자료를 선택합니다.

  2. 02

    규칙 확인·승인

    제안된 문체·디자인·출처 등을 확인하고 승인한 Company Pack의 버전을 관리합니다.

  3. 03

    패키지 생성과 도입

    회사 Pack과 기본 스킬 8개, 필요한 언어 모듈을 묶습니다. 도입은 권한이 있는 관리자가 별도로 수행합니다.

Company Pack은 회사별 규칙과 근거를 묶은 것입니다. 공개 내보내기 도구는 원본 PDF/PPTX와 서체 파일을 동봉하지 않습니다. 패키지 생성·설치·새 요청의 동작 확인은 각각 별도 과정입니다.

B / 직원이 요청한 뒤의 내부 흐름

제작 창구가 필요한 전문 스킬로 연결합니다.

예를 들어 “임원이 검토할 4주 파일럿 제안서를 일본어 PPTX로 만들고 싶다”고 요청합니다. 직원이 내부 스킬 이름을 하나씩 고를 필요는 없으며, 제작 창구가 부족한 조건을 확인합니다.

문서 제작 창구report-html-pptx

목적·독자·언어·형식을 정리하고, 회사별 요청에서는 사용할 승인된 Company Pack을 명시적으로 선택·검증합니다.

  1. 01

    구성과 필요한 조사

    독자의 판단을 기준으로 구성을 계획합니다. 근거가 부족하면 조사하고 필요에 따라 구성으로 돌아갑니다.

    Architecture / Research
  2. 02

    집필과 언어 확인

    원고·수치·조건을 정리합니다. 도입한 일본어·한국어 모듈로 대상 언어를 확인합니다.

    Writing / Language
  3. 03

    디자인과 이미지

    확정한 원고를 HTML로 구성합니다. 필요한 도표·이미지를 선택하고 이미지 제작이 필요한 경우 해당 스킬을 사용합니다.

    Design / Visual Assets
  4. 04

    HTML 실제 표시 확인

    본문·서체·여백·도표·이미지 배치를 확인합니다. 문제가 있으면 관련 과정으로 돌아갑니다.

    Browser / Editorial QA
  5. 05

    PPTX 출력과 최종 확인

    PPTX를 요청하면 편집 가능한 요소로 변환하고 글자 보존·표시·편집성과 미확인 범위를 확인합니다.

    HTML-to-PPTX / QA

도입한 환경의 AI가 역할별 지침과 스크립트를 사용해 진행하는 구조입니다. 조사와 이미지 제작은 필요할 때 수행합니다. 원고만·HTML만 요청한 경우 해당 단계에서 완료하며, 부분 수정은 영향을 받는 과정과 그 뒤의 확인을 갱신합니다.

실제 내부 스킬과 역할 보기

기본 스킬 8개에 일본어·한국어 교정 모듈을 필요에 따라 추가합니다. 언어 모듈을 도입하지 않았다면 전문 언어 확인을 실시한 것으로 표시하지 않습니다.

OUTPUT / EDITABLE POWERPOINT

HTML로 다듬은 자료를, 편집 가능한 PowerPoint로.

HTML은 원고와 레이아웃을 제작하고 확인하는 원본입니다. 출력할 때 배치와 글자의 조판 정보를 측정해 PowerPoint의 텍스트·도형·이미지로 다시 구성합니다.

본문·수치·표의 글자
편집 가능한 텍스트
지원하는 도형·괘선
편집 가능한 도형과 선
사진·일러스트
글자와 분리해 이미지로 배치

회의 직전의 수치 수정, 담당자명 변경, 거래처에 맞춘 문장 조정을 PowerPoint에서 이어갈 수 있습니다. 디자인 재현성과 업무에 필요한 편집성을 함께 확인하는 구조입니다.

변환 구조와 업무 활용 전 확인 사항
  1. 01

    HTML 제작

    원고와 레이아웃 확인

  2. 02

    배치와 글자 측정

    위치·크기·서체 읽기

  3. 03

    PPTX 구성

    텍스트·도형·이미지 배치

  4. 04

    출력 확인

    표시와 편집성 검증

편집 가능한 요소로 처리할 수 있는 범위는 지원하는 HTML/CSS에 따라 달라집니다. 복잡한 장식이나 일부 SVG는 이미지로 유지합니다. 표의 글자가 편집 가능해도 PowerPoint의 표 개체로 변환된다는 뜻은 아닙니다.

출력 후 실제 PowerPoint 또는 LibreOffice에서 글자 누락·줄바꿈·서체·이미지 위치·편집성을 확인합니다. 서체와 실행 환경에 따라 차이가 생길 수 있어 모든 HTML의 완전한 일치를 보장하지는 않습니다.

현재 공개된 웹 예제는 HTML 표시를 확인한 예제입니다. 이 예제들의 PPTX 변환과 실제 표시까지 검증한 것은 아닙니다. 실제 생성·변환·출력 확인은 도입한 환경에서 수행합니다.
