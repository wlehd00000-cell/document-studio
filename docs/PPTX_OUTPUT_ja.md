# HTMLから編集できるPowerPointへ

[日本語トップ](../README.ja.md) · [文書ガイド一覧](README.md) · [サイトの出力図解](https://document-studio-public-experiment.wlehd00000.chatgpt.site/#pptx-output)

HTMLは、原稿とレイアウトを制作・確認する原本です。求められた場合は、その表示情報を使ってPowerPointのテキスト・図形・画像を組み立てます。会議前の数値修正や担当者名・文章の更新を、PPTX上で続けるための工程です。

## 変換の4段階

| 段階 | 行うこと |
|---|---|
| 1. HTMLで制作・確認 | 原稿、数値、書体、余白、図表、画像の実際の収まりを確認 |
| 2. 位置と文字を実測 | ブラウザー上の位置・寸法・文字組みを読み取る |
| 3. PPTXを組み立てる | 対応する文字・図形を編集可能な要素にし、画像を別に配置 |
| 4. 出力を確認 | 文字の保持と、実際のPowerPoint/LibreOfficeでの表示・編集性を確認 |

担当スキルは [`html-to-pptx`](../skills/html-to-pptx/SKILL.md) です。HTMLの確認結果と、PPTX出力の確認結果は別に扱います。

## PowerPointで変更できる範囲

| 元の要素 | 出力の扱い | 業務での変更例 |
|---|---|---|
| 対応する本文・数値・表の文字 | 編集可能なテキスト | 金額、担当者名、説明文の更新 |
| 対応する図形・罫線 | 編集可能な図形・線 | 矢印や区切りの位置調整 |
| 写真・イラスト・複雑な装飾 | 必要に応じて画像 | 写真や図版の差し替え・移動 |

表の文字が編集できても、PowerPointの表オブジェクトになるとは限りません。複雑な装飾や一部SVGは画像にする場合があります。対応範囲はHTML/CSSと変換環境によります。

## 業務で使う前の確認

1. HTMLの原稿・数値・単位・前提条件と、PPTXの文字を照合します。
2. 対象のPowerPointまたはLibreOfficeで開き、文字欠落、改行、書体、画像位置を見ます。
3. 必要な本文・数値が編集できることを実際に確認します。全要素がネイティブになるとは扱いません。
4. 確認した環境・書体・実施したチェックと、未確認の範囲を記録します。

任意のHTMLの完全一致や、どのPCでも同じ表示を保証する仕組みではありません。必要な変換環境・依存関係は[技術ガイド](TECHNICAL_GUIDE.md)と[変換スキルの仕様](../skills/html-to-pptx/SKILL.md)を確認してください。
