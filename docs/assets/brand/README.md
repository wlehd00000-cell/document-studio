# Document Studio cover assets

The README cover combines the four original [document samples](../../../examples/document-collection/README.md) with an original paper-sculpture illustration. The sample pages retain their source aspect ratios; captions and typography are composed in HTML.

- `cover.html`: editable cover layout, 1800 × 1200 CSS pixels.
- `document-studio-cover.jpg`: rendered README cover, JPEG quality 95.
- `paper-sculpture.png`: transparent brand artwork, revised with the built-in image generation tool on 15 November 2026. The complete, low horizontal paper sculpture is contained beside the heading without cropping or a rectangular backdrop. It is decorative concept art, not a screenshot or document output.

To edit the cover, open `cover.html` from the downloaded repository. Keep the repository folders intact so the sample images and fonts resolve. Render the `.canvas` element at its native size after `document.fonts.ready` resolves.

## Artwork prompt

> Edit the supplied paper sculpture into an isolated brand illustration for a shallow horizontal website header. Preserve the tactile ivory paper and deep forest-green palette with only a tiny burnt-amber accent. RECOMPOSE the sculpture into a LOW, WIDE arrangement: three broad, gracefully folded paper sheets gently fanned horizontally, like a considered editorial paper study. The whole sculpture must be visible from edge to edge, no cropping. Center the sculpture in the canvas, with generous completely transparent margins on every side; it should occupy the middle 45 percent of canvas height and about 80 percent of width, so its complete silhouette is much wider than tall. Realistic matte paper fibers, crisp folds, very subtle soft contact shadow below only. Genuine transparent background, no beige rectangular panel, no floor plane, no backdrop, no frame. Do not include lettering, symbols, documents with writing, screens, logos, or props. Premium and restrained, not towering like a wall. It will be placed beside dark-green text on an ivory background; keep the entire paper object comfortably contained.
