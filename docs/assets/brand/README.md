# Document Studio cover assets

The README cover combines the four original [document samples](../../../examples/document-collection/README.md) with an original paper-sculpture illustration. The sample pages retain their source aspect ratios; captions and typography are composed in HTML.

- `cover.html`: editable cover layout, 1800 × 1200 CSS pixels.
- `document-studio-cover.jpg`: rendered README cover, JPEG quality 95.
- `paper-sculpture.png`: original brand artwork, generated with the built-in image generation tool on 14 November 2026. It is decorative concept art, not a screenshot or document output.

To edit the cover, open `cover.html` from the downloaded repository. Keep the repository folders intact so the sample images and fonts resolve. Render the `.canvas` element at its native size after `document.fonts.ready` resolves.

## Artwork prompt

> Create an original premium editorial brand illustration for an open-source business document studio. Landscape 3:2 composition, high resolution. A sculptural arrangement of a few thick ivory paper sheets folding into elegant architectural planes, one deep forest-green sheet and a very small burnt-amber edge, resting on a seamless warm ivory background (#f4f1e9). Museum-quality still-life 3D photography, tactile matte paper fibers, very precise folds, soft directional daylight, subtle contact shadows, calm Swiss editorial design. The sculpture occupies the right two thirds with breathing room, left third is clean empty ivory. Simple and restrained, visually memorable even at small size. No letters, no numbers, no logos, no text, no mock document content, no screens, no people, no stationery props, no glossy plastic, no gradients as decoration. This is a standalone brand artwork, not a screenshot of a software product.
