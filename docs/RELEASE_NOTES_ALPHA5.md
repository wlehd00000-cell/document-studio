# Document Studio v0.1.0-alpha.5 — first download-ready alpha preview

**AI models change. Your company's document standards shouldn't.**

Document Studio is an MIT-licensed, review-first toolkit for extracting **authorized** document style evidence, approving reusable **Company Packs**, and packaging custom document-production plugins for ChatGPT. Its priority is shared organizational writing, terminology, design and layout standards **without freezing every page into one template**.

### Download the two ready-to-inspect packages

- **`document-studio-starter-v0.1.0-alpha.5.zip`** — 8 core skills + optional Korean and Japanese modules. Generic toolkit, no employer-specific content.
- **`demo-retail-documents-v0.1.0-alpha.5.zip`** — the same skills with an independently authored fictional retail Company Pack. For a safe first trial, **not** for real-brand fidelity claims.
- **`SHA256SUMS.txt`** — checksums for both ZIPs.

[3-step download & installation guide](https://github.com/wlehd00000-cell/document-studio/blob/main/docs/DOWNLOAD_AND_INSTALL.md) · [Workspace admin pilot checklist](https://github.com/wlehd00000-cell/document-studio/blob/main/docs/WORKSPACE_ADMIN_GUIDE.md)

### How to use

Download an archive → check its SHA256 → inspect it → use an eligible account's **Plugin Creator** to register it (or ask a workspace admin to publish through supported controls) → test on invented/non-sensitive content. **Downloading is not installation.**

### Current limits — read before corporate rollout

- **Alpha preview, not stable 1.0.** This release is for trials and feedback.
- **No one-click company-document → installed plugin automation.** Human source review/approval and installation are separate.
- The **public exporter blocks private/restricted source-derived Company Packs**; internal-only corporate-pack distribution remains a planned feature.
- **No promise of identical output across AI models/versions.** Cross-model compatibility and model-upgrade regression checks have not been certified.
- Chromium-dependent browser layout QA has not completed for all cases; independent editable PowerPoint appearance/editability QA is required.
- Never redistribute company originals, private text, licensed font binaries, or employer branding without permission.

**For contributors:** please report installation blockers, first-plugin usage feedback, and reproducible bugs using fictional data. This pre-release makes the software easier to try, not more thoroughly certified.
